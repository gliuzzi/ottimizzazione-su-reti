# Contribuire

Il materiale è in fase di preparazione. Correzioni, segnalazioni ed esempi
aggiuntivi potranno essere proposti tramite issue o pull request dopo la
pubblicazione del repository.

Prima di proporre una modifica al codice:

1. installare il progetto con `python -m pip install -e ".[dev]"`;
2. eseguire `pytest`;
3. mantenere la convenzione NetworkX per domande e offerte;
4. accompagnare le nuove funzioni con almeno un test.
